Bug reports that speak

Real bugs I discovered, documented, and saw through to fix. Each report shows how I think — step by step.

BUG-0042 Critical

Cart total breaks on quantity change

Environment: Chrome 121 · macOS Sonoma · E-Commerce App v2.3.1
Steps to reproduce:
1. Add item (SKU-8812, $49.99) to cart
2. Open cart → click quantity "+" twice
3. Observe total
ExpectedTotal: $149.97 (3 × $49.99)
ActualTotal: $99.98 (stale session state)
Root cause: Quantity update dispatched before session total recalculated — race condition in Redux reducer. → Fixed in v2.3.2
BUG-0067 Major

Filter resets on mobile pagination

Environment: Safari 17 · iOS 17.3 · iPhone 15
Steps to reproduce:
1. Apply filter: Category = "Electronics" + Sort = "Price low-high"
2. Scroll to bottom
3. Tap "Next page"
4. Observe filter chips
ExpectedFilters remain applied
ActualFilters cleared to default
Root cause: Mobile paginator fetch didn't persist filter params from URL query string. → Fixed in v2.3.5

· How I test

Methodology, not guesswork

Every test I run follows a repeatable cycle — from understanding the feature to documenting the result.

01

Understand

Read requirements, raise edge-case questions, review acceptance criteria before writing a single test.

02

Design

Apply boundary value analysis, equivalence partitioning, and error guessing. Prioritise by risk and impact.

03

Execute

Run manual checks, automate regression paths, retest fixes. Screen record flaky behaviour as evidence.

04

Report

Write clear repro steps, classify severity, attach logs. Close the loop when the fix is verified in staging.
